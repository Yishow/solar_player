## ADDED Requirements

### Requirement: Refine circuits settings table visual design and density

The system SHALL visual-refine the circuits settings table (`cs-table`) by adding hover row highlighting, optimizing layout spacing in icon and display columns, and applying modern visual treatments to thresholds pills.

#### Scenario: Table row highlights on hover and aligns elements compactly

- **WHEN** user hovers over a row in the circuits settings table
- **THEN** the row background color SHALL highlight smoothly
- **AND** the columns for icons and display slots SHALL align their internal input elements compactly to avoid vertical row stretching
